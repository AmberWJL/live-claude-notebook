A local MCP server for your coding notes

Give any MCP agent a notebook: it can save what you ask it to keep and look up what you saved before. The notes are Markdown files on your computer; the server reads and writes them and nothing else.

Install

npm install -g github:AmberWJL/live-claude-notebook

It needs Node.js 18 or newer and has no other dependencies. The server runs with live-notebook mcp over stdio.

The tools

ToolWhat it does
save_noteSaves text as a note, with an optional title, notebook, type and tags.
search_notesFinds notes whose title, text or tags contain the words, newest first.
read_noteReads one note in full.
list_notebooksLists notebooks with their note counts and newest titles.

Add it to your agent

Claude Code

claude mcp add --scope user live-notebook -- live-notebook mcp

Cursor: ~/.cursor/mcp.json, and Gemini CLI: ~/.gemini/settings.json

{ "mcpServers": { "live-notebook": { "command": "live-notebook", "args": ["mcp"] } } }

VS Code (Copilot agent mode): run MCP: Add Server…, choose Command (stdio), enter live-notebook mcp.

Codex: ~/.codex/config.toml

[mcp_servers.live-notebook]
command = "live-notebook"
args = ["mcp"]

On Windows, use "command": "cmd", "args": ["/c", "live-notebook", "mcp"] if the agent cannot find the command.

Things to ask

  • "Save that explanation to my notebook under Ops."
  • "Search my notes for idempotency."
  • "Before you start, check my notes on our deploy process."

What it can touch

Only the notes folder (~/.claude/live-notebook, or LIVE_NOTEBOOK_HOME). Paths outside it are refused. It makes no network requests. Each note records which agent saved it.
