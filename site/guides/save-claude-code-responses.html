Guide · Claude Code

Save Claude Code responses as Markdown notes

Claude Code answers scroll away. Live Notebook keeps the ones worth keeping as Markdown files you own, and finds them again in a second.

Install the plugin

In a Claude Code session, run:

/plugin install live-notebook --marketplace AmberWJL/live-claude-notebook

Answer y to add the marketplace. It is on right away and in every later session. It needs Claude Code 2.1.293 or newer and Node.js 18 or newer.

Save a whole reply

Under every reply there is a dim Save to notebook control. Press it, pick a notebook, press Save. The reply is saved word for word, code blocks included.

Save part of a reply

  1. Select the lines in the conversation.
  2. Type /save. The selection opens in the notebook pane, ready to edit.
  3. Or type /save followed by any text to save that.

Find it again

/notebook opens the pane: notebooks, notes, and a search over every word. /notebook web opens the web notebook in your browser, where you can edit, pin, move and export notes.

Where the notes are

Each note is a file under ~/.claude/live-notebook/notes/<Notebook>/ with a small front matter block: title, notebook, type, tags, dates and where it came from. Edit the files in any editor and the plugin picks up the change.
