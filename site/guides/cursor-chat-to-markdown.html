Save Cursor chat replies as Markdown notes

Cursor's agent explains a fix, you close the chat, and the explanation is gone. Here are three ways to keep it as a Markdown note on your own computer. They also work for Copilot Chat in VS Code.

1. The extension: copy, then save

Install the Live Notebook extension (steps). Then:

  1. Press the reply's Copy button in the chat.
  2. Run Live Notebook: Save Clipboard as Note from the command palette.
  3. Pick a notebook. The reply is saved exactly as written.

Code in an editor works too: select it, right-click, Save Selection as Note. Search Notes finds anything you saved.

2. Ask the agent: the MCP server

Install the command with npm install -g github:AmberWJL/live-claude-notebook and add it to ~/.cursor/mcp.json:

{ "mcpServers": { "live-notebook": { "command": "live-notebook", "args": ["mcp"] } } }

Now say "save that to my notebook under Payments" or "what did I save about retries?". The agent passes the text itself, so for an exact copy prefer the extension or the hook.

3. Keep every reply: the hook

Add to ~/.cursor/hooks.json:

{ "version": 1, "hooks": { "afterAgentResponse": [{ "command": "live-notebook hook" }] } }

Each reply then waits in the web notebook's Inbox (the newest 50). Open one, pick a notebook, Save as note, or Discard. Run live-notebook open to see it.

Why not read Cursor's chat history directly?

Cursor keeps chats in an internal database with no public interface, and editors do not let one extension read another's chat. Live Notebook uses only the ways Cursor documents: the clipboard, MCP and hooks.

Where the notes go

Plain .md files in ~/.claude/live-notebook/notes/, the same folder Live Notebook for Claude Code uses. Nothing is uploaded. Privacy details.
