Notes for AI coding

Keep the answers worth keeping.

Live Notebook saves the useful parts of your AI coding chats as Markdown notes on your own computer. Search them, tidy them, and come back to them. Works with Claude Code, Cursor, VS Code and any agent that speaks MCP.

Install View on GitHub

The web notebook runs on your computer. Every note is a plain .md file.

Save from wherever you code

Claude Code

One click under every reply

A plugin adds a Save to notebook control under each reply, and /save for a selection. Notes show in a pane beside the chat.

VS Code · Cursor

Copy a reply, save it

An editor extension saves a copied chat reply or your selection as a note, word for word, and searches your notes from the command palette.

Any MCP agent

Just ask

"Save that to my notebook." "What did I save about retries?" A local MCP server gives Cursor, Copilot, Codex and Gemini CLI four note tools.

Hooks

Nothing slips by

Optionally, an agent's hook keeps each reply in an inbox, so you can file the good ones later, exactly as written.

Your notes stay yours

  • Notes are Markdown files in a folder on your computer. Open them in any editor, back them up, put them in git.
  • No account, no cloud, no analytics. The web notebook answers only its own page and loads nothing from the internet.
  • One folder for every tool: a note saved in Cursor shows up in Claude Code and the web notebook too.
  • The one optional extra: in Claude Code, a small Claude model can pick a note's type and tags, only for notes saved there, and you can turn it off. What stays local.

Questions

Does it upload my conversations?

No. Notes are written to a folder on your computer and read from there. Nothing is sent to a Live Notebook server; there isn't one.

Can an extension read Copilot's or Cursor's chat by itself?

No editor lets one extension read another's chat. So you copy the reply and save it, or let an agent hook keep each reply in the inbox, or ask the agent to save it through MCP.

What happens to my notes if I stop using it?

They are Markdown files. They stay where they are, readable by any editor.

Is it free?

Yes. It is open source under the MIT license.
