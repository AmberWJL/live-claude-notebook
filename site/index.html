Keep the answers worth keeping.

Live Notebook lives right inside Claude Code desktop: a Save to notebook button under every reply keeps it as a Markdown note on your own computer, and a pane beside the chat finds it again in a second. Brainstorming, designing or building with Claude, the insights worth keeping land in the same chat as everything else; now they are one click from a notebook you can edit, add your own notes to, and export as one file. No account, no cloud.

What the film shows
  1. In Claude Code desktop, a developer starts designing sharing for notebooks. Claude's first reply is an insight ("Model the question, not the table"): the Save to notebook button under it lights up, one click opens the Live Notebook pane beside the chat with the reply ready, and Save keeps it in a Design notebook as an Insight.
  2. A side question lands in the same chat (optimistic vs pessimistic locking) and gets an answer worth keeping too. Then it is back to the feature: the design, "implement it", and a rush of ten messages scrolls the chat to the bottom while the pane stays put.
  3. "Which one was it again?" The chat rewinds to the locking reply; the same button saves it as a Learning. The pane now lists both notes.
  4. Each is a plain Markdown file in ~/.claude/live-notebook/notes/Design, with a little front matter: title, notebook, type, tags.
  5. Searching for "sharing" finds both notes at once and opens the web notebook.
  6. In the web notebook, the developer adds their own line to the locking note ("My note: grants gets a version column"), then presses New Note and writes the decision down in their own words.
  7. Export on the Design notebook saves the whole notebook as one Markdown file, design.md: a design doc, ready to share with the team.
  8. No account, no cloud: just Markdown files on your computer, to open in any editor, back up or keep in git.
  9. The soundtrack is music and sound effects only, synthesized for the film; there is no speech.
