Keep the answers worth keeping.

Live Notebook saves the useful parts of your AI coding chats as Markdown notes on your own computer, and finds them again in a second. Claude Code, Cursor, VS Code and any agent that speaks MCP. No account, no cloud.

Cursor · VS Code · MCP

Then: in Claude Code · in Cursor and VS Code · with any MCP agent · what stays local

What the film shows
  1. An AI coding agent explains how to retry payment timeouts with backoff, and then the conversation scrolls on and the answer is gone.
  2. Rewound, the answer gets a Save to notebook button. One click turns it into a plain Markdown file with a little front matter: title, notebook, tags, who wrote it.
  3. Claude Code, Cursor, VS Code and any MCP agent all save into the same folder, ~/.claude/live-notebook/notes, sorted into notebooks.
  4. Searching for "retry" finds the note at once and opens it in the web notebook.
  5. No account, no cloud: just Markdown files on your computer, to open in any editor, back up or keep in git.
