Notes for Claude Code

Keep the answers worth keeping.

Live Notebook saves the useful parts of your Claude Code chats as Markdown notes on your own computer. One click under any reply; search them, tidy them, and come back to them later.

Install View on GitHub

The web notebook runs on your computer. Every note is a plain .md file.

How it works

Save

One click under every reply

A dim Save to notebook control sits under each Claude Code reply. Press it, pick a notebook, done: the reply is kept word for word.

Excerpt

Just the lines you need

Select part of a reply and type /save, or /save followed by any text. Edit it before it is saved.

Find

Search every word

/notebook opens a pane beside the chat with your notebooks and a search over everything you saved.

Edit

A notebook in your browser

/notebook web opens the web notebook: edit as formatted Markdown, pin, move, archive and export notes.

Your notes stay yours

  • Notes are Markdown files in a folder on your computer. Open them in any editor, back them up, put them in git.
  • No account, no cloud, no analytics. The web notebook answers only its own page and loads nothing from the internet.
  • Edit a note anywhere: in the pane, in the web notebook, or in any editor. Each picks up the others' changes.
  • The one optional extra: in Claude Code, a small Claude model can pick a note's type and tags, only for notes saved there, and you can turn it off. What stays local.

Install

In a Claude Code session, run:

/plugin install live-notebook --marketplace AmberWJL/live-claude-notebook

Needs Claude Code 2.1.293 or newer and Node.js 18 or newer for the web notebook. macOS, Windows and Linux.

Questions

Does it upload my conversations?

No. Notes are written to a folder on your computer and read from there. Nothing is sent to a Live Notebook server; there isn't one.

Does it work in Cursor or VS Code?

Today it works where Claude Code runs: the terminal and the desktop app. Support for other editors is being worked on separately.

What happens to my notes if I stop using it?

They are Markdown files. They stay where they are, readable by any editor.

Is it free?

Yes. It is open source under the MIT license.
